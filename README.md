# Portafolio de Mario Ayala (versión con Bootstrap)

Es mi portafolio para el trabajo final del curso de Desarrollo Web de IDAT (ciclo 1, 2026-IIIA). Son cinco páginas en HTML con Bootstrap 5.3. El CSS propio es un solo archivo, con los colores, las fuentes, las animaciones y el dibujo de los corchetes del encabezado.

Las páginas son `index.html` (inicio), `proyectos.html`, `caso-aybiz.html`, `como-trabajo.html` y `contacto.html`.

Bootstrap y las fuentes de Google se cargan desde internet, así que hace falta conexión para verlo bien. El formulario de contacto todavía no envía nada, porque el sitio es estático.
